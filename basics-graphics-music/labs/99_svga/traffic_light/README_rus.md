# traffic_light пример для svga_mitator
Это пример автомата Мили (FSM), который управляет светофором.
Контролируемый светофор рисуется на интерфейс VGA или SVGA. Его можно наблюдать с помощью вывода VGA платы FPGA (проверено на de10_lite) или тестировать с помощью svga_imitator и Vivado.

Также реализуются тесты на функциональность как FSM, так и вывода VGA/SVGA.

## 1. Структура проекта
Пример интегрируется с basic-graphics-music, особенно для синтеза. Скрипты BGM функциональны, за исключением 02_simulate_rtl.bash, так как моделирование и тесты выполняются с использованием Vivado и svga_imitator.

lab_top.sv, а также другие модули находятся в корневой папке примера.
Тестбенчи и их зависимости в ./tb

Скрипты для запуска симуляции или теста с использованием Vivado расположены в ./run_sim_vivado

Сначала необходимо следовать инструкциям от ./run_sim_vivado/env_user.sh.in, затем выполнить "source ./run_sim_vivado/env.sh" для инициализации Vivado.

Теперь можно запустить тесты (./run_sim_viado/sim_01 и ./run_sim_vivado/sim_02) выполнив

compile.sh
elaborate.sh
c_run_0.sh или c_run_1_sh или g_run.sh
в каталоге требуемого моделирования

## 2. Модули
lab_top.sv - основной модуль этого примера, содержит логику для рисования светофора на экране
ellipse.sv - используется для определения того, принадлежит ли точка (пиксель) к незаполненной эллипсу.
complex_filled_ellipse.sv - используется для определения того, принадлежит ли точка (пиксель) заполненному эллипсу с формой светофорной лампы.
line.sv - используется для определения того, принадлежит ли точка (пиксель) прямой линии
FSM_1.sv - автомат Мили, который выводит состояния красных, желтых и зеленых ламп
bind_FSM_1.sv - bind для FSM, используется для тестирования покрытия (coverage).
Tick_05s_generator.sv - выводит более медленную тактовую частоту для таймера FSM. Параметр IS_SIMULATION управляет длительностью тика. Если IS_SIMULATION=1, один тик длится около 0,5µs, чтобы сократить время моделирования. Если IS_SIMULATION=0 (значение для синтеза) один тик равен 0,5s. Для сравнения, красный свет горит 20 тиков.


## 3. Тесты
В sim_01 есть только 1 тест
Он выводит 8 изображений на svga_mitator для проверки отаброжения на VGA. Эти 8 кадров являются всеми возможными комбинациями 3 ламп. Этот режим требует IS_SIMULATION = 2. FSM отключен, так как он не тестируется. Требуется svga_imitator, запущенный параллельно Vivado.

В sim_02:
Тест 1 - проверяет, верна ли последовательность состояний автомата и, следовательно, включенных ламп
Test 2 - имеет аналогичную цель, но реализуется с использованием covergroups и transition bins. 
Выход VGA отключен, так как он не тестируется.
